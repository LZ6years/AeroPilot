## 1. 我想做什么

我想做一个面向无人机仿真环境的自然语言导航 Agent。

用户不需要写固定动作命令，只需要用自然语言描述任务，例如：

```text
我有点口渴，帮我找一下周围有没有售货机，告诉我在哪里
```

系统会把自然语言任务拆成多个阶段。每个阶段根据当前图像、无人机位姿、历史动作和安全约束，进行短步执行、观察反馈和继续规划。

核心不是让模型一次性生成完整动作序列，而是做一个闭环系统：

```text
理解任务 -> 分阶段 -> 看图和状态 -> 短步动作 -> 执行后再观察 -> 判断是否完成 -> 出错自动修复
```

## 2. 为什么要这样做

现有 UAV-VLN / Aerial Navigation 方法有几个问题：

- 很多方法偏端到端，模型直接预测动作，出错后很难解释为什么错。
- UAV 在三维空间里飞，和地面机器人不同，有高度、偏航、距离和视角变化问题。
- 语言任务往往不是一步完成的，而是有阶段性，例如先转向、再找目标、再靠近、最后悬停。
- 多模态大模型虽然能看图和理解语言，但直接让它控制无人机不安全，也容易输出非法动作。
- 当前 benchmark 常关注成功率，但缺少对错误原因、恢复能力和执行过程的可解释分析。

所以我的想法不是直接训练一个黑盒模型，而是研究如何把 VLM 稳定地接入 UAV 控制闭环。

## 3. 创新点

### 创新点 1：可解释的 UAV-VLN 闭环 Agent 架构

不是让模型直接端到端控制无人机，而是拆成：

```text
语义阶段规划 + 多模态上下文 + 短步动作 + 执行后判断
```

每一步都能记录和解释，方便分析失败原因。

这和很多端到端 VLA / VLN 方法不同：我的重点不是只追求一个动作预测结果，而是让整个飞行过程可观察、可诊断、可恢复。

### 创新点 2：面向 UAV 的多模态记忆与上下文机制

把无人机的图像、位姿、历史动作、任务阶段组织成统一上下文，让 VLM 在每一步决策时都能看到当前状态和历史信息。

未来可以继续扩展：

- 多帧图像融合
- 局部地图记忆
- 目标候选记忆
- 飞过区域记忆
- 长距离任务中的历史压缩与目标追踪

这个方向适合对应长距离 UAV-VLN，例如后续接入 AerialVLN 时，可以重点验证记忆机制在长路径、多阶段指令中的作用。

### 创新点 3：Agent Recovery 错误恢复机制

现有很多系统中，模型 JSON 输出错了、动作非法了，就直接失败。

我的系统可以让模型根据错误类型选择修复工具，自动改写输出。

例如：

- 语义解析把“起飞20m”错误写成 `takeoff`，系统可以修成“上升20m”语义阶段。
- 动作规划输出了禁止动作，系统可以修成合法动作。

这可以提升系统鲁棒性，也方便统计模型常见错误。

### 创新点 4：短距离和长距离 benchmark 结合评估

我计划用两个层次的 benchmark 来评估：

- **UAV-Flow**：更偏短程、细粒度语言控制，适合看动作执行、短步闭环和轨迹跟随。
- **AerialVLN**：更偏长距离、复杂语言和持续导航，适合看长期记忆、阶段规划和偏航恢复能力。

这样可以避免只在一种任务上验证。短程任务能看底层控制是否稳，长程任务能看系统是否真的具备持续导航能力。

## 4. 准备做什么实验

### 4.1 UAV-Flow benchmark：短程细粒度控制

使用 UAV-Flow 的短程指令、场景和参考轨迹。

主要评估：

- 成功率
- nDTW
- 实际轨迹 vs 参考轨迹
- 每步动作是否符合指令
- 失败原因分类

这个实验主要回答：

> 我的 Agent 能不能稳定执行一句短程、细粒度的自然语言飞行指令？

### 4.2 AerialVLN benchmark：长距离导航能力

后续接入 AerialVLN，看长距离 UAV-VLN 下的效果。

AerialVLN 的特点是路径长、动作多、语言复杂，更适合验证：

- 长距离任务分阶段是否合理
- 飞行过程中是否能利用历史记忆
- 偏航后是否能恢复
- 长指令中多个地标和动作是否能持续跟踪
- 多模态上下文是否能提高长程导航成功率

这个实验主要回答：

> 我的 Agent 在长路径、复杂语言和持续观察条件下，是否比简单 VLM prompting 更稳定？

### 4.3 消融实验

可以对比：

- 不用图像 vs 使用图像
- 不用记忆 vs 使用记忆
- 不用 Recovery vs 使用 Recovery
- 大步动作 vs 短步动作
- 只做短程闭环 vs 加入长程阶段记忆

这些实验用来说明每个模块是否真的有用，而不是只展示一个系统。

- 自然语言任务解析

- 图像、位姿、动作历史上下文
- 动作约束和安全检查

未来还可以继续加强的部分：

- Agent Recovery 完整接入

- AerialVLN benchmark 接入
- 失败原因自动统计和可视化报告

可以按照：

```text
先验证短程闭环稳定性 -> 再验证视觉目标任务 -> 再接 UAV-Flow -> 最后扩展到 AerialVLN 长距离导航
```



> 构建一个面向无人机视觉语言导航的可解释、可恢复、多模态闭环 Agent。它不是直接让大模型黑盒控制无人机，而是通过语义阶段规划、视觉记忆上下文、动作约束和错误恢复机制，让 VLM 能够更稳定、安全、可分析地完成 UAV 自然语言导航任务。短期用 UAV-Flow 验证细粒度控制，后续接入 AerialVLN 验证长距离导航能力。
