# 飞行教学知识

知识按飞行能力与当前判断问题组织。主提示保留短的反馈循环，目录提供各入口的用途与边界，
正文解释原理、选择方法、预期变化、结果检验和纠正。加载数量不作为目标，已加载正文继续复用。
六个在线名称保持稳定，不删除整篇知识或参考文件。基础动作反馈原则常驻主提示；参数选择或
运动响应需要进一步判断时才加载完整基本操纵正文，不自动全量加载，也不在每轮重复正文。

| 能力 | 在线入口 | 主要判断 |
|---|---|---|
| 基本飞行操纵 | `basic_flight_control` | 初始试探、位移和转角尺度、升降与斜向分量、实际响应校准 |
| 观察与态势感知 | `visual_target_task_reasoning` | 地标身份、遮挡、历史图片变化、观察位置 |
| 航迹与地标导航 | `route_traversal_and_passage` | 路线连续性、到达路口、条件转弯、经过顺序 |
| 接近、停驻与任务结束 | `approach_and_standoff` | 剩余位置关系、末段调整、停止与降落要求 |
| 异常判断与恢复 | `abnormal_situation_recovery` | 视野恶化、实际结果不符、未知执行、恢复或停止 |
| 专项机动 | `orbit_and_surround` | 切向进度、径向修正、方向与覆盖 |

原高度知识已拆分：操纵方法和斜向公式归入基本操纵，观察高度归入态势感知，降落判断归入
接近与结束。旧名称不再用于在线加载；历史正文和加载回执保持原样。

每个核心正文保留五个标题与一个短例子，长度不超过 2400 字符；较长的对照例子通过
references 按需加载。数值用于说明方法，不构成固定步长。目录实际提供 `name/description`，
修改选择说明时必须修改 description，不能只修改 summary。

物理窗口固定为一个工具调用；执行反馈和新图片返回后再决策。单次移动仍可包含多个速度
分量，调用数量限制不等于位移限制。反馈保留真实参数、位移与观测标识，不自动判断到达。
校准使用同一次动作前后的可用图片与实测运动；缺图时说明实际可用的证据，不能虚构图片比较。
路线知识区分看见路口、到达路口与进入转弯道路；停止判断分别核对目标身份、此前路线条件和
最终位置关系。视野恢复清晰后仍需重新核对路线与目标，不能直接据此认定路线正确。

## AerialVLN 到达建议与报告边界

只有 AerialVLN 的调用方协议说明正式评分的最终水平距离容差为 20 米，并建议在目标身份、
位置关系及可用距离证据支持时，争取进入约 10 米的停止区域。测距无效或几何不适用时不能
编造“已进入 10 米”；继续结合 RGB、目标关系与实际运动判断。该建议不覆盖路线顺序、
独立升降要求或最终位置关系，不放入通用飞行知识或常驻主提示。

派生报告的“临界到达”仅标记正常完成且 `20 < distance_to_goal <= 25` 的记录。只有有效距离
以及明确的 `completed / stopped / error` 结束信息才可判断；字段缺失标为未知，阻塞、报错
及基础设施失败不算临界到达。它不改变正式 SR 或成功／失败转换。新版建议只用于后续任务，
旧实验的原始请求、Transcript、评分和冻结源码不变；报告单独记录生成器版本。

## 图片配置

本次单动作窗口十例的 208 次导航模型请求没有 top-down 或 CONTEXT IMAGE；模型使用当前／
历史 RGB 和附带的工具证据图。报告中的俯视轨迹图含实际与参考路径，供事后审阅，不是模型
看到的地图或光学俯视图。主提示仅在“提供时”解释 CONTEXT IMAGE，本轮保持模型图片配置、
20 张预算及压缩阈值。轨迹图和模型输入图应分别审计，不能由报告图片推断模型已见过它。
