# Learning Movement Response

## Inspecting A Hidden Continuation

A road is visible beyond a nearby building, but the straight path toward it
intersects the facade. Choose a reachable viewing position along known clear
space, adjust position or heading, and inspect the connected passage before
advancing. The visible road is not evidence that the direct path to it is clear.

## Comparable Feedback

A modest forward move produces measured translation but little visual change along
a coherent route. The next move may extend progress if its continuation is supported.
The same displacement near a junction rapidly expands its road edges; shorten the
next action to inspect the entry. Speed-duration values express requested travel,
not a measured target range. Compare available pictures immediately before and
after that same action with its requested parameters and measured response. Match
the same cue across the two pictures; a different action's image or a different
target's apparent size is not the same feedback pair.

## Resetting An Estimate

After a turn, body-forward has a new world direction. After ascent, objects project
from a different height. After switching targets, apparent sizes differ. Recheck
calibration rather than transferring an old pixels-per-meter ratio to these cases.
If an old view is unavailable, state the retained evidence and inspect the present
scene; do not claim to have compared pictures that were not available.

## Missing One Or Both Pictures

If the before image is unavailable, measured motion can still show how the vehicle
responded to the request. Use the current view to choose a supported next observation
position, without claiming that a landmark grew or moved across the picture.
If the after image is unavailable, retain the measured response and the last usable
view, but do not treat the old scene as current visibility. Obtain available current
evidence before selecting a move that depends on new geometry. If motion is also
unknown, do not assume the vehicle stayed still or blindly repeat the request.

## Vertical Progress

Requested climb, actual height change and observed obstruction relations answer
different questions. Meeting a numeric climb does not guarantee passing above an
obstacle. While far from the height relation, seek meaningful progress; near a
surface or endpoint, shorten correction. Angled flight preserves horizontal and
vertical components while applicable. Missing clearance remains unknown.
