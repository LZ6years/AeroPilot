# 工具结果及时保存：离线验证

使用 `F:\conda_env\flyagent\python.exe -m tests.manual.tool_completion_probe --output <独立短目录>`。
入口只调用构造假工具，不请求模型、不启动模拟器、不加载视觉模型。

探针对比 `fbbec23` 的 Runtime 批次保存方法与候选方法；两者使用当前执行器，
基线不传完成回调。因此它衡量 Runtime 保存策略的差异，不代表完整旧版本性能。
一线程和四线程分别交替运行各 31 次，首调用单列，剩余 30 次计算 P50/P95。
输入为两个立即返回的小型结构化结果，不能据此推断真实视觉或导航速度。

普通耗时与额外诊断分开。诊断记录返回到凭据保存延迟、文件字节量、Python
分配峰值及进程 RSS；基线无逐项保存诊断，不将缺失值写为零。

父进程监督故意以退出码 23 结束的子进程：前序工具等待，后序工具完成并保存
凭据后触发退出。父进程保留退出记录、stdout/stderr、资源记录，读取已保存凭据，
输出 `review/review.html`、案例时间线及完整审计页。图片为明确构造的色块，
不是导航实验或感知结果。所有记录保留原地，不自动续跑或伪造工具结果。

完成回调只在执行器调用线程运行。普通异常形成失败结果；致命异常停止新提交，
继续接收已运行任务的结果。保存回调失败后不重复调用失败的保存器，原始错误继续
传播。任何尚未交付主线程的结果都不具有持久性保证。
